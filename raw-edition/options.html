思源笔记本地 API 地址，默认 http://127.0.0.1:6806
在思源笔记 设置 → 关于 → 访问授权码 中设置，留空则关闭鉴权
可先留空点击「测试连接」，会列出所有笔记本及 ID
支持 /文件夹/子目录 格式，留空保存到笔记本根目录

配置步骤：
1. 确保思源笔记已启动（默认端口 6806）
2. 如需鉴权：设置 → 关于 → 设置访问授权码
3. 笔记本 ID 留空，先点「测试连接」查看可用笔记本列表
4. 复制目标笔记本 ID 填入上方输入框
5. 再次测试连接确认成功

保存到支持 WebDAV 协议的网盘（坚果云、Nextcloud 等）
WebDAV 服务端点地址。坚果云: https://dav.jianguoyun.com/dav/
坚果云请使用「账户信息 → 安全选项 → 应用密码」
网盘上的保存目录，不存在时会自动创建
开启后，在保存路径下自动创建以论坛域名为名的子文件夹（如 linux.do → /Discourse收集箱/linux/）

配置步骤（以坚果云为例）：
1. 登录坚果云网页版
2. 进入「账户信息 → 安全选项」
3. 添加「应用密码」，复制生成的密码
4. 填入上方：URL=https://dav.jianguoyun.com/dav/，用户名=邮箱，密码=应用密码
5. 点击「测试连接」确认配置正确

通过百度网盘开放 API 保存帖子到网盘
点击按钮弹出百度登录页进行授权，授权后 token 自动刷新
百度网盘 /apps/ 下的应用目录名，默认 ob-sync
应用文件夹下的子目录名
开启后，在保存路径下自动创建以论坛域名为名的子文件夹（如 linux.do → /apps/ob-sync/Discourse收集箱/linux/）

配置步骤：
1. 勾选「启用百度网盘保存」
2. 点击「百度网盘授权登录」，在弹出页面登录百度账号并授权
3. 授权成功后可点击「测试连接」查看网盘使用情况
4. 可选：开启「按论坛域名自动分文件夹」自动归类

3. 复制目标知识库的 namespace 填入上方
4. 再次测试连接确认成功
